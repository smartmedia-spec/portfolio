## Deployment with GitHub Pages

This repository includes a GitHub Actions workflow at `.github/workflows/deploy.yml` that publishes the site whenever changes are pushed to `main`.

One-time setup:
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment → Source**, select **GitHub Actions**.
3. Save the setting. The workflow will deploy the site on the next push to `main`, or it can be started manually from the **Actions** tab.

After a successful deployment, GitHub Pages will show the published website URL under **Settings → Pages**. The expected project-site address is:

https://smartmedia-spec.github.io/portfolio/
