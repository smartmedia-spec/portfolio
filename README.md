# Jefa John Kombo — Personal Portfolio

A responsive personal portfolio website for Jefa John Kombo, bringing together his professional experience in digital media and creative production with his work in coding, robotics and technology education.

## Portfolio sections

- Introduction and professional positioning
- About
- Digital media and technology education expertise
- Selected robotics, electronics and learning projects
- Professional experience
- Software, tools and technical capabilities
- Education and languages
- Contact information

## Built with

- HTML5
- CSS3
- Vanilla JavaScript

No framework or build step is required.

## Run locally

Open `index.html` in a modern web browser.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)`.
5. Save and wait for GitHub Pages to publish the site.

The public repository is:
https://github.com/smartmedia-spec/portfolio

## Content and accuracy

Project summaries describe documented project concepts, teaching resources and technical explorations. Build evidence, photographs, videos, wiring diagrams, code samples and test results should be added as each project is fully documented. Do not interpret a project description as confirmation of completed physical testing.

Professional experience and education are based on the CV supplied for this portfolio.
